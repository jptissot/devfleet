# Airlock Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fork agent-sandbox into `~/repos/airlock` and reshape it into one long-lived container per repo that devfleet can drive by path.

**Architecture:** The launcher stays a single bash script plus three python libs. Identity moves from `$PWD` to the repo root (parent of `git rev-parse --git-common-dir`); the repo is bind-mounted at its own host path so Orca's `<repo>/.worktrees/<n>` checkouts and their absolute `gitdir:` pointers resolve unchanged; per-mission entry becomes `engine exec -w <dir>` into the repo's existing container.

**Tech Stack:** bash, python3 (tomllib), podman/docker, bats + a fake engine on PATH.

**Spec:** `~/repos/devfleet/docs/superpowers/specs/2026-07-24-airlock-design.md`

## Global Constraints

- Rename map, applied everywhere: `agent-sandbox` → `airlock`, `.agent-sandbox/` → `.airlock/`, `AGENT_SANDBOX_*` → `AIRLOCK_*`, container `agentbox-<name>-<hash>` → `airlock-<name>-<key>`, base image `agent-sandbox-base:latest` → `airlock-base:latest`, project image `agent-sandbox-<name>-<hash>:latest` → `airlock-<name>-<key>:latest`.
- Exit-code contract: `0` ready/succeeded, `10` Containerfile unapproved or drifted, `11` config gate unapproved, `20` not scaffolded, `21` image missing, `22` rebuild pending, `1` other error.
- State root: `${XDG_STATE_HOME:-$HOME/.local/state}/airlock/<repokey>/` containing `home/`, `usr-local/`, `image.hash`, `config.hash`.
- Repo key: `sha256(realpath repo root)[:12]`; repo root = parent of `git rev-parse --git-common-dir`, else `$PWD`. Overridable by `AIRLOCK_KEY`, then `[sandbox] key`.
- Kept from the ancestor: `--cap-drop=ALL`, `--security-opt no-new-privileges`, `--read-only`, tmpfs `/tmp`, pasta/bridge networking, both approval gates and their content-addressed fingerprints, `env > config.toml > default` precedence, `LOCAL_ONLY` keys, `:z` vs `:Z` discipline, "warn, never silently recreate".
- Codebase conventions (ancestor `AGENTS.md`): comments are the spec — update them, never strip; `|| rc=$?` at every `python3` call, never `if ! python3`; init.py exit codes `0/1/2/3` unchanged; teach `test/helpers/fake-engine` any new engine call.
- Every task ends green: `bats test/*.bats` (minus `integration.bats`, which is opt-in behind `AIRLOCK_IT=1`).

- [ ] **Step 3: Implement identity**

Replace the identity block:

```bash
# --- Repo identity ---
# One container per repo, not per directory: Orca puts mission worktrees at
# <repo>/.worktrees/<n>, so keying on the repo root lets every worktree share one
# container, one image, and one persisted home. The repo root is the parent of
# git's *common* dir — in a linked worktree, git-dir is .git/worktrees/<n> while
# git-common-dir is still the main repo's .git.
resolve_repo_dir() {
  local common
  if common="$(git rev-parse --git-common-dir 2>/dev/null)"; then
    # git prints a relative path ('.git') from inside the main checkout.
    case "$common" in /*) ;; *) common="$(pwd)/$common" ;; esac
    dirname "$(realpath -m "$common")"
  else
    pwd
  fi
}
PROJECT_DIR="$(pwd)"          # the exec's working directory
REPO_DIR_TARGET="$(resolve_repo_dir)"
PROJECT_NAME="$(basename "$REPO_DIR_TARGET")"
```

`REPO_KEY` resolves after `load_config` (config may set it), so compute the derived value here and override later:

```bash
DERIVED_KEY="$(printf '%s' "$REPO_DIR_TARGET" | sha256sum | cut -c1-12)"
```

and after `load_config`:

```bash
REPO_KEY="${AIRLOCK_KEY:-${CFG_SANDBOX_KEY:-$DERIVED_KEY}}"
CONTAINER_NAME="airlock-${PROJECT_NAME}-${REPO_KEY}"
IMAGE_TAG="airlock-$(printf '%s' "$PROJECT_NAME" | tr '[:upper:]' '[:lower:]' | tr -cs 'a-z0-9._-' '-')-${REPO_KEY}:latest"
STATE_ROOT="${XDG_STATE_HOME:-$HOME/.local/state}/airlock/$REPO_KEY"
```

`CONFIG_DIR`, `CONFIG_FILE`, `PROJECT_CONTAINERFILE` become `$REPO_DIR_TARGET/.airlock/...` — committed content stays in the repo. `IMAGE_HASH_FILE` and `FINGERPRINT_FILE` become `$STATE_ROOT/image.hash` and `$STATE_ROOT/config.hash`.

`init` needs `IMAGE_TAG` before `load_config` runs; give that branch the same `REPO_KEY` fallback chain minus config (`${AIRLOCK_KEY:-$DERIVED_KEY}`).

Move the `mkdir -p "$STATE_ROOT/home"` and the `.inputrc`/`.bashrc`/`starship.toml` seeding out of the script top into a `seed_state()` function, called from the launch and build paths only (Task 7 depends on this).

```bash
# --- status subcommand ---
# A machine-readable answer to "can a bunkered agent launch here?". Inspects
# only: never builds, never creates, never seeds state — asking a question must
# not have a side effect.
airlock_state() {
  [ -f "$PROJECT_CONTAINERFILE" ] || { printf 'not-scaffolded'; return 20; }
  containerfile_needs_approval && { printf 'unapproved'; return 10; }
  if config_gate_reason >/dev/null \
     && [ "$(cat "$FINGERPRINT_FILE" 2>/dev/null || true)" != "$CONFIG_FP" ]; then
    printf 'unapproved'; return 11
  fi
  "$ENGINE" image inspect "$IMAGE" >/dev/null 2>&1 || { printf 'no-image'; return 21; }
  printf 'ready'; return 0
}
```

The `--json` form prints `state`, `code`, `repo`, `key`, `image`, `container`, `container_exists`, `container_running`, and `reason` (the gate text, or `null`).

```bash
# Busy = any process besides PID 1's `sleep infinity`. The container is shared by
# every mission in the repo, so recreating it kills work that is not yours.
container_busy() {
  container_running || return 1
  [ "$("$ENGINE" top "$CONTAINER_NAME" 2>/dev/null | tail -n +2 | grep -cv 'sleep infinity')" -gt 0 ]
}
# The image a running container was created from, vs the image its tag points at
# now. A rebuild does not touch a live container — mounts and image are pinned at
# create — so this is reported and waited out rather than acted on.
container_image_stale() {
  container_exists || return 1
  local created current
  created="$("$ENGINE" inspect -f '{{.Image}}' "$CONTAINER_NAME" 2>/dev/null)"
  current="$("$ENGINE" image inspect -f '{{.Id}}' "$IMAGE" 2>/dev/null)"
  [ -n "$created" ] && [ -n "$current" ] && [ "$created" != "$current" ]
}
```
